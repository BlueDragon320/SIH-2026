================================================================================
 AIR-GAPPED AGENTIC AI WORKBENCH - 1-CLICK EXECUTABLE LAUNCHERS
================================================================================

METHOD A: 1-CLICK EXECUTABLE LAUNCHERS (STARTS ALL SERVICES & REDIRECTS TO BROWSER)
--------------------------------------------------------------------------------
• On Linux / macOS (Terminal or Double-Click):
    ./start.sh
    # or native compiled binary:
    ./workbench
    # or universal python launcher:
    ./start.py

• On Windows (Command Prompt or Double-Click):
    start.bat

All launchers automatically:
  1. Detect local models and start Ollama (Port 11434)
  2. Launch FastAPI Orchestrator (Port 8000)
  3. Launch Modern React Web UI on 0.0.0.0:5173
  4. Automatically open and redirect your default browser to http://localhost:5173

--------------------------------------------------------------------------------
METHOD B: MANUAL STEP-BY-STEP STARTUP
--------------------------------------------------------------------------------
STEP 1: Start Ollama Runtime (Port 11434)
  ollama serve

STEP 2: Start FastAPI Backend (Port 8000)
  python -m uvicorn orchestrator.main:app --host 127.0.0.1 --port 8000

STEP 3: Start Modern React Web Interface (Port 5173)
  cd frontend-web
  npm run dev -- --host 0.0.0.0 --port 5173

ACCESS URLS:
  • Web UI:      http://localhost:5173 (or http://<LAN_IP>:5173 from other devices)
  • Swagger API: http://127.0.0.1:8000/docs
