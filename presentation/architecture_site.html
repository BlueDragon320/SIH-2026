orchestrator/tools/sandbox.py · files.py · docgen.py · spreadsheet.py — Bubblewrap kernel namespace isolation on Linux. Windows fallback runs with subprocess timeout.

Bubblewrap Flags — from sandbox.py execute_python_code()

--unshare-net Removes network namespace entirely — container has no network stack at all. No sockets, no DNS, no HTTP.
--unshare-ipc Isolates IPC namespace — child cannot access host shared memory, semaphores, or message queues.
--unshare-pid New PID namespace — child process cannot see or signal host processes.
--ro-bind / / Read-only bind-mount of entire host filesystem — Python interpreter and libraries accessible but immutable.
--tmpfs /tmp Ephemeral RAM filesystem for /tmp — cleared on exit, MPLCONFIGDIR set here for matplotlib cache.
--bind WORKSPACE WORKSPACE Only the task workspace directory is read-write. Entire host filesystem is read-only except this path.
Windows fallback: shutil.which("bwrap") is None → plain subprocess.run([sys.executable, script_path]) with timeout=15s. network_isolated=False in result. Exit code 1 on socket open attempt.

File Path Allowlisting — tools/files.py

def _safe_path(filename, workspace):
    resolved = (workspace / filename).resolve()
    if not str(resolved).startswith(
            str(workspace.resolve())):
        raise PermissionError(
            "Path traversal blocked")
    return resolved

# Blocks: ../../../etc/passwd
#         /absolute/paths
#         symlink escapes out of workspace

5-Step Ingestion Pipeline

1
MIME Detection — loaders.py
python-magic inspects raw file header bytes (not extension). Routes: PDF → PyMuPDF, DOCX → python-docx paragraph extractor, PNG/JPG/WEBP/BMP → VisionOCRPipeline.
2
PDF Classification — loaders.py
PyMuPDF extracts text from all pages. If total extracted text < 50 chars AND image blocks are detected → classified as scanned PDF → routes to OCR pipeline. Otherwise: native PDF text extraction.
3
OCR Pipeline — VisionOCRPipeline.analyze_visual_document()
fitz (PyMuPDF) renders each PDF page as PNG at 200dpi. PNG encoded as base64. POST to http://127.0.0.1:11434/api/generate with {"model":"moondream","prompt":"Extract all text…","images":["<base64>"],"stream":false}. Response text concatenated per page.
4
Chunking & Embedding — rag/embed.py
Text split into ~512-token chunks with overlap. POST to Ollama /api/embeddings with model nomic-embed-text. Fallback: if Ollama offline → SHA-256 hash of chunk text → deterministic 768-dim float vector (ensures ingestion never fails).
5
ChromaDB Storage — rag/vector_store.py
Chunks stored at data/chroma_db/ (on-disk persistent). Each chunk: embedding vector + metadata {doc_id, filename, page_num, chunk_index, text}. Collection persisted across restarts.

NetworkMonitor — sample_network_status()

Measurement
psutil.net_io_counters(pernic=True) called each API poll. Computes per-interface byte deltas since last call. Divides by elapsed time → rate in B/s.
Interface Classification
Internal (excluded): lo, docker*, veth*, br-*
External (monitored): eth0, wlan0, enp*, Wi-Fi — anything not in the internal prefix list
Egress Verdict
if external_rate_sent < 50.0:
    airgap_status = "SECURE_AIR_GAPPED"
else:
    airgap_status = "TRAFFIC_DETECTED"

verified_zero_egress = (external_bytes_sent == 0)
Socket Audit
psutil.net_connections(kind="inet") — each socket flagged as external if remote IP is not 127.x or ::1. External socket list returned in API response.
Live Verification

AuditLogger — Dual-Write · SQLite + JSONL

Every event is written atomically to both data/audit.db (SQLite) and data/audit_log.jsonl (append-only). SQLite enables querying; JSONL is the tamper-evident immutable record.
